## 实测基线

- 客户端：嘉立创EDA专业版 `V4.1.60`，窗口标题形如 `<工程名> | 嘉立创EDA(专业版) - V4.1.60`
- 进程名：`lceda-pro.exe`（安装路径因机器而异，不作为定位依据）
- 平台：Codex（v1 验收，2026-10-02 至 10-03）；Claude（v2 试跑原理图、PCB 与导出，2026-10-19）
- 窗口尺寸：`1920 x 1080` 与 `1282 x 721` 下都能重新定位保存和 DRC 入口

## 操作对照

| 操作 | 教程入口 | V4.1.60 实测 | 说明 |
|---|---|---|---|
| 保存 | — | 可访问性标签 `保存全部(Ctrl+S)` | 已验证 |
| 原理图 DRC | `设计 - 检查DRC` | `设计 > 检查DRC` | 已验证；原理图检查也叫 DRC，没有单独的 ERC |
| 原理图转 PCB | `设计 - 原理图转PCB` / `更新/转换原理图到PCB` | `Alt+I`，随后在弹窗中“应用修改” | 已验证；教程中两处写法不同，以窗口为准 |
| 板框 | `放置 - 板框` | `放置 > 板框 > 矩形`，属性中输入 `50mm` 生效 | 已验证 |
| 自动布线 | `布线 - 自动布线` | `布线 > 自动布线 > 所有网络 / 所选网络 / 所选器件网络 / 自动布线设置` | 已验证（Codex、Claude）。“所有网络”直接出预览并在右侧显示布通率和过孔数，点“确认”应用；不会先弹设置窗口，GND 也会被布线，要忽略网络需先进“自动布线设置” |
| PCB DRC | `设计 - 检查DRC` | 工具栏 `检查DRC`，或 `设计 > 检查DRC` | 已验证（Codex、Claude）。结果面板显示检查项数和问题数，同一面板附带下单报价广告，不点 |
| 铺铜 | `放置 - 铺铜区域` | `放置 > 铺铜区域 > 矩形 / 圆形 / 多边形`；矩形点两个对角，弹出“轮廓对象”窗口 | 已验证（Claude）。网络自动选了 GND；图层默认是顶层，铺底层时要在窗口里把图层改成“底层”；默认不保留孤岛、全填充 |
| 导出 Gerber | `导出 - PCB制板文件(Gerber)` | “一键导出” → “导出Gerber” → 询问是否先查 DRC → 系统保存窗口（默认“下载”，zip） | 已验证（Claude）。压缩包含 13 个文件：顶底层、丝印、阻焊、钢网、板框、钻孔等 |
| 导出 BOM | `导出 - 物料清单(BOM)` | 先弹“推荐器件标准化”提示，可选“导出BOM”跳过；BOM 窗口点“导出BOM” | 已验证（Claude）。XLSX，含供应商编号 |
| 导出坐标 | `导出 - 坐标文件(CPL)` | 窗口点“导出” → 系统保存窗口 | 已验证（Claude）。XLSX，mm |
| 放置器件 | `放置 - 器件` / `Shift+F` | `放置 > 器件/复用模块`；对话框内可切换“立创商城 / 嘉立创EDA”搜索，结果标注基础库或扩展库、显示库存和价格 | 已验证（Claude）。`Shift+F` 需要画布有焦点，否则无效，用菜单更稳；放下一个后会继续放同一器件，位号自动加一并保留旋转，按 `ESC` 退出 |
| 导线 | `放置 - 导线` / `Alt+W` 或 `W` | `Alt+W`（专业版主题）；左键确定拐点 | 已验证（Claude）。终点落在引脚上不会自动结束，右键一次才结束；终点落在另一条导线上会自动结束并生成连接点。结束后有时会退出导线模式，所以每条线开始前都重新按 `Alt+W`，再看工具栏导线按钮是否高亮 |
| 连接点 | `放置 - 连接点标识` / `Alt+J` | T 形接入、从导线中间或拐角起画时自动生成 | 已验证（Claude）。本次 6 个连接点都是自动生成的，没有手动放 |
| 网络标签 | `放置 - 网络标签` / `Alt+N` | 菜单可见 `Alt+N` | 未实操 |
| 网络标识 | `放置 - 网络标识` | 子菜单：VCC、+5V、地、模拟地、保护地；点击放置后可连续放 | 已验证（Claude） |
| 旋转 / 翻转 | 空格 / `X`、`Y` | 空格 = 逆时针 90°；`X` = 左右镜像（放置过程中可用） | 已验证（Claude）。`Y` 未测 |
| 移动器件、导线段 | 拖动 | 一次性拖拽不生效；要“按下 → 分几步移动 → 松开”。拖动导线的水平段时，相连的竖段会跟着伸缩 | 已验证（Claude） |
| 单路布线 | `布线 - 单路布线` / `W` | 尚无记录 | 按教程执行 |

## 实测中发现的问题

- 引脚端点不一定落在 0.05 inch 网格上（实测 SW4 的 SS-3235S-L3、U1 的 TAB）。在 220% 缩放下目测连线，终点会吸附到相邻网格，比引脚高一格，看起来连上了，实际是悬空。原理图 DRC 会报“单网络，仅连接了一个元件引脚”和“元件引脚悬空”。修正方法：放大到 600% 以上，把导线水平段拖到引脚高度。
- 对话框关闭后，嘉立创窗口有时不响应鼠标移动：十字光标停在原地，点击会落在旧位置（实测把一个 LED 放到了图纸边框上）。每次关闭对话框后，先移动鼠标并确认十字光标跟着走，再点击。
- 在元件树中选中元件，画布会自动跳到该元件，视图随之平移。之后要重新截图校准坐标。
- 用户可能在两次会话之间改过工程：本次重新打开时 PCB 已经转换并布局好，还多了一行放在顶层铜上的文字。开工前先看清现状，再决定从哪一步接着做。
- 原理图里执行“更新/转换原理图到PCB”时，如果 PCB 已同步，会提示“无变更，原理图与PCB已经匹配”，并自动切到 PCB 标签页。

- 选中新器件后，属性面板偶尔仍显示上一个器件的数据：关键属性要读两次。
- 器件名、供应商封装、3D 模型与实际 PCB 封装可能互相矛盾：以实际 PCB 封装为准。
- 只改一个电阻值后更新 PCB，旧布线被整体清除：同步前后必须对比。
- 首次保存时工程曾显示为同名目录，关闭重开后变成单个 `.eprj2` 文件，另有备份目录：保存路径以关闭重开后的结果为准。
