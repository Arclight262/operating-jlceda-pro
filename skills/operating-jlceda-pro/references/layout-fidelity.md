# 按图复刻版面

图片输入的默认要求：画出来的原理图在器件摆放和接线方式上与原图一致，看图的人能一眼对上。只有用户明确选择“只要求电气一致”时，才可以重新整理版面，并在报告中写明。

“一致”指相对关系一致，不要求像素级对齐：

- 器件数量相同，每对相邻器件的上下左右关系不变；
- 每个器件的朝向（横放或竖放、引脚 1 / 正极 / 阳极朝哪边、是否镜像）相同；
- 每条导线的走向和折点顺序相同，水平段和竖直段与图对应；
- 连接点的位置相同，图上不连接的交叉在画布上也不连接；
- 网络标签、电源和地标识的位置与朝向相同；图上用标签连接的地方用标签，用导线的地方用导线，不互相改画。

## 1. 建版面表

以图片中电路区域的左上角为原点，横向向右、纵向向下，各归一化到 0–100，并记下图片的宽高比。逐项记录：

```text
器件
| 位号 | 中心 (x, y) | 横/竖 | 引脚1/正极/阳极朝向 | 镜像 | 备注 |
| U1   | (45, 40)   | 竖    | 引脚1 在左上        | 否   | 8 脚芯片，左 4 右 4 |
| R1   | (20, 15)   | 竖    | —                   | 否   | 在 U1 左上方 |

导线（从端点到端点，按折点顺序）
| 编号 | 起点      | 折点序列                  | 终点      |
| W1   | R1.1      | 上→(20,5) 右→(45,5)       | U1.8      |
| W2   | J1(32,40) | 左→(20,40)                | R2.2      |

连接点：J1 (32, 40)，J2 (60, 70)
不连接的交叉：X1 (40, 55)，W3 与 W5 交叉
标签与标识：GND 在 (45, 90) 朝下；网络标签 OUT 在 (80, 45)
```

每一项同样标 `已确认`、`待确认` 或 `无法识别`。版面表和器件表、网络表一起给用户确认后再开画。

## 2. 映射到画布

1. 按 `tutorials.md` 查看原理图设置中的网格；画布上始终吸附网格。
2. 选一个比例，把版面坐标换成画布坐标：画布坐标 = 起点 + 版面坐标 × 比例。比例要让图上最近的两个器件在画布上不重叠，并留出画导线的空间。整张图用同一个比例，不要局部压缩或拉伸，否则相对关系会变形。
3. 放置后用右侧属性面板或状态栏核对器件位置。属性面板是否提供可输入的坐标字段，以当前窗口为准；有就直接输入，没有就拖动后读数核对。

## 3. 放置顺序

1. 先放决定框架的器件：主要芯片、连接器、大器件。
2. 再按版面表放外围器件。
3. 每放一个器件，立即用空格旋转、用 `X` / `Y` 翻转到版面表要求的朝向（见 `tutorials.md`），观察确认后再放下一个。
4. 最后放电源和地标识、网络标签。

## 4. 库符号与图不一致

库符号的引脚排布可能和图上画法不同（例如图中芯片的引脚位置和库符号不一样）。处理顺序：

1. 器件的位置和朝向仍然按图。
2. 导线在符号外侧按图的走向布置，尽量保持折点顺序。
3. 差异大到无法保持接线走向时，停下问用户，给出选项：换一个引脚排布更接近的库符号、接受差异、或调整局部版面。没有用户同意，不自己新建或修改符号。
4. 所有差异写进报告。

## 5. 连线

1. 按版面表的折点顺序画导线（`放置 - 导线`），不走最短路径，不合并图上分开画的线段。
2. 图上有连接点的位置，按教程放“连接点标识”。导线十字交叉默认不连接，漏放连接点会导致网络断开。
3. 图上十字交叉不连接的地方，确认画布上没有连接点。
4. 每画完一条导线，确认两端确实吸附在目标引脚或节点上。视觉上接近不算连接。

## 6. 核对

保存后截取画布，与原图逐区对照，记录在报告的“版面核对”表中：

| 项目 | 核对方法 |
|---|---|
| 器件数量 | 逐区计数 |
| 相对位置 | 每对相邻器件的上下左右关系 |
| 朝向 | 横竖、引脚 1 / 极性方向、镜像 |
| 导线 | 每条导线的折点数和各段方向 |
| 连接点 | 位置集合与原图一致；不连接的交叉没有连接点 |
| 标签与标识 | 位置、朝向、文字 |

版面核对和 `schematic.md` 的电气核对都通过，才算复刻完成。有差异时逐条列出原因：库符号限制、画布限制或用户已同意的调整。未经用户同意的差异不能称为完全复刻。
