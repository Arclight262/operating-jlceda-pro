# 完成报告

先给结论和需要用户做的事，再给细节。没有的项写“无”，不要删掉。

```text
结论：<编辑验收通过 / 生产就绪未验证 / 生产就绪已验证 / 未完成（原因）>
需要你做的事：<待确认项、未解决项、下单前建议自己核对的内容>

工程：<工程名>    保存路径：<关闭重开后的最终路径>
客户端版本：<窗口实际显示>    平台：<Claude Code / Codex / DeepSeek Harness / 其他>
完成内容：<原理图、PCB 实际做了什么>

检查结果
- 原理图 DRC：致命 <n>，错误 <n>，警告 <n>，信息 <n>；保留的警告及原因
- PCB DRC：<问题数>，共检查 <项数>；未布网络 <n>
- 未验证项：<DRC 覆盖不到或没有依据的项目>

版面核对（图片输入）
| 项目 | 结果 | 差异与原因 |
| 器件数量 / 相对位置 / 朝向 / 导线走向 / 连接点 / 标签与标识 | 一致或差异 | <库符号限制、用户同意的调整等> |
复刻等级：<严格复刻 / 只要求电气一致>

器件：<选用的库器件、封装、立创编号；有库字段矛盾时注明>
教程与窗口的差异：<菜单名、快捷键与教程不符之处>
新观察到的入口：<本次首次确认可用的菜单、按钮、快捷键，供补入 ui-reference.md>
备份：<是否备份、位置>
证据：<窗口标题、画布观察>
```

关于完成等级：

- 编辑验收通过：输入要求、连接、封装、板框和当前规则检查都满足。
- 生产就绪已验证：在上一条基础上，制造约束、设计规则和关键电气、机械检查都有明确依据并已完成。
- DRC 为零、自动布线 100%、3D 预览无碰撞，都不能单独证明可以生产。
