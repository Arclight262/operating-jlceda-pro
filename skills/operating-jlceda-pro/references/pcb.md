# PCB

步骤顺序与学习中心快速入门一致：转换 → 板框 → 布局 → 布线 → 铺铜 → DRC。入口见 `tutorials.md`。

## 1. 转换前

- 原理图已保存，原理图 DRC 已处理或解释。
- 用封装管理器逐个核对封装：每个器件都有封装；符号引脚编号与封装焊盘编号一致；引脚数不多于焊盘数。教程说明，这些问题会让转换中止。
- 确认板框尺寸、层数、安装孔、接口位置。没有规定、但会影响成品的项先问用户。

## 2. 约束台账

开始布局前，为本项目记录用到的约束：对象或网络、数值和单位、容差、来源、状态（`适用` / `待确认` / `不适用`）。

- 可接受的来源：用户确认的要求、器件数据手册、接口标准、目标制造商当前工艺能力、已确认的层叠方案。
- 教程、文章和其他项目中的数值只能用来发现需要问的问题，不能作为本项目的默认值。用户要求“照教程的值”时，记录为“用户指定，适用性未验证”。
- 只为工程中实际存在的功能块（大电流、开关电源、高速、差分、模拟敏感、射频、热、安规）启用专用检查。不存在的，标为不适用。

## 3. 原理图到 PCB

1. **转换前记录**：保存工程，记下器件数、网络数、已有走线和当前 DRC 结果。已有工程且尚未确认备份时，先按 `intake.md` 询问。
2. **执行**：首次用 `设计 - 原理图转PCB`；已有 PCB 用原理图的“更新PCB”或 PCB 中的 `设计 - 导入修改信息`。菜单名随版本不同，以窗口为准（V4.1.60 实测可用 `Alt+I`）。
3. **确认导入信息弹窗**：默认全选。逐项看清变更内容，取消不需要的项后再点“应用修改”。
4. **转换后对比**：比较器件、封装、网络、飞线、走线和板框的前后变化。教程提醒：原理图增删器件后，PCB 导线所属网络通常要手动修改。实测中只改一个电阻值，更新后旧布线被整体清除。
5. **出现非预期的删线、网络变化或器件移动**：立即停下报告。未经用户明确授权，不得重新布线、删除网络，也不得再次同步覆盖现场。

首次转换时，编辑器会参考原理图中的器件位置大致摆放封装。

## 4. 板框

`放置 - 板框`，选矩形、圆形或多边形。选中后在右侧面板设置尺寸。V4.1.60 实测：输入带单位的 `50mm` 可以生效；画布单位为 mil 时显示为约 `1968.5mil`。确认板框闭合、尺寸正确。

## 5. 布局

1. 先放受机械位置约束的器件：连接器、安装孔、指示灯、按键。
2. 再放决定关键路径的器件：去耦电容靠近对应芯片，开关电源先收紧电流环路（仅在存在时）。
3. 最后放没有特殊约束的器件。用 `布局` 菜单对齐、分布、组合。
4. 每次移动或旋转后观察位号、封装和飞线；有极性器件和连接器同时核对朝向。

## 6. 布线

- **手动布线**：`布线 - 单路布线`（`W`，或专业版主题下 `Alt+W`）。左键加拐点，`L` 切换拐点，`T` / `B` / 数字键切层并自动加过孔，`V` 放过孔，`Backspace` 回退。线宽和间距来自约束台账，按教程“布线宽度”设置。
- **布线顺序**：先布约束台账中的关键网络，再布普通网络。没有关键网络时，按连接关系自然推进。
- **自动布线**（`布线 - 自动布线`）：只用于用户明确允许的普通网络。V4.1.60 中选“所有网络”会直接出预览（布通率、过孔数），点“确认”才应用，不会先弹设置窗口；要排除某些网络（如留给铺铜的 GND），先在“自动布线设置”里设置“忽略网络”，再运行。“已有导线/过孔”保持“保留”，不能选“移除”；关键走线先手动完成并锁定；需要铺铜连接的网络（如 GND）加入“忽略网络”。教程说明自动布线效果一般，完成后要逐条核对，必要时手动调整。

## 7. 铺铜

`放置 - 铺铜区域`，在弹窗中设层和网络；修改后在右侧面板点“重建铺铜区”。重建后检查网络、孤岛和未布网络。

## 8. PCB DRC 与完成

1. `设计 - 检查DRC`，逐项处理。
2. 至少核对：原理图与 PCB 的器件、位号、封装一致；板框闭合且尺寸正确；必需网络全部布通，没有意外短路；极性、接口方向和机械约束正确；剩余警告都有解释。
3. 约束台账中标为适用、但 DRC 覆盖不到的项目，人工复查或用对应工具验证。
4. 完成等级：电源与地线宽、间距、回流、热、EMC、装配可达性或制造商规则中，任何适用项缺少明确依据，就报告“生产就绪未验证”并列出缺口。不得自行编造规则值；当前规则集只能证明“符合自己设定的规则”。

## 9. 导出生产文件（用户明确要求时）

前提：PCB DRC 为零或剩余项都有解释；工程已保存。导出不改变完成等级，报告里仍按 `report.md` 写明“生产就绪未验证”的缺口。

1. **Gerber**：`导出 - PCB制板文件(Gerber)`，选“一键导出”，点“导出Gerber”。客户端会询问是否先检查 DRC，选“是”。在保存窗口确认位置后保存（V4.1.60 默认是“下载”文件夹，文件为 zip）。
2. **BOM**：`导出 - 物料清单(BOM)`。客户端会建议先做“器件标准化”；器件都来自立创商城且带立创编号时，可以直接点“导出BOM”，并在报告里说明没有做标准化。默认格式 XLSX，包含位号、封装、值、制造商和供应商编号。
3. **坐标文件**：`导出 - 坐标文件(CPL)`，默认 XLSX、单位 mm，点“导出”。
4. **核对**：确认文件确实保存了（能读取文件系统时列出文件和大小），Gerber 压缩包里至少有顶层、底层、丝印、阻焊、板框和钻孔文件，BOM 行数和器件数与原理图一致。

导出窗口和成功提示里都有“PCB下单”“一键下单”“SMT备料下单”“元件下单”等按钮。一律不点；关闭提示框时用右上角的 ×。

## 高级功能

差分对、等长、xSignals、约束区域、铺铜优先级、缝合孔、泪滴，只在工程确有对应对象、且约束来源明确时使用。使用前读 `tutorials.md` 中对应的教程页，按教程操作；规则创建后分别确认“规则已定义”“已绑定对象”“实际检查通过”。缺少会决定几何或电气结果的输入时，不试填经验值。
