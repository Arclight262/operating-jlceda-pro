# UI 基线与版本适配

## 已观察事实

观察日期：2026-10-02 至 2026-10-03。

- 客户端进程：`D:\Program Files (x86)\lceda-pro\lceda-pro.exe`，进程名 `lceda-pro.exe`。
- 已验证窗口标题：`嘉立创EDA(专业版) - V4.1.60`。
- 当前已安装并观察的版本：`V4.1.60`。
- 开始页“快速开始”区域可见 `新建工程`、`打开工程`、`新建元件库`、`新建器件`、`新建封装`、`新建3D模型`、`设置` 和 `关于` 等入口。
- 开始页顶部可见 `文件`、`视图`、`工具`、`高级`、`设置` 和 `帮助` 菜单文字；其内部命令位置和语义尚未逐项验证。
- 在 `V4.1.60` 的原理图编辑器中，已实际使用 `设计 > 检查DRC`；界面将原理图规则检查也标为 `DRC`，不要擅自把客户端标签改写成 `ERC`。
- 在 `V4.1.60` 中，已实际使用 `Alt+I` 将原理图变更导入 PCB，随后在变更对话框中执行“应用修改”。
- 在 PCB 编辑器中，已实际使用 `放置 > 板框 > 矩形`、`布线 > 自动布线 > 所有网络` 和工具栏 `检查DRC`。
- 板框属性接受带单位的 `50mm`、`30mm` 输入；当前画布单位为 `mil` 时，宽度提交后显示为约 `1968.5mil`。这只是输入与显示行为，不代表其他属性都支持相同单位转换。
- 在 `1920 x 1080` 与 `1282 x 721` 两种窗口尺寸下，均可通过重新观察后的可访问性文本定位 `保存全部(Ctrl+S)` 与 `检查DRC`。两次 PCB DRC 均完成且结果为零问题。

这些只是该次观察的基线，不代表所有版本或所有工作区都相同。除上面列出的已实测入口外，精确库条目、编辑器内工具、菜单路径和快捷键未验证前都不得作为事实写入操作步骤。

## 自适应定位

1. 每次操作前读取当前窗口列表，要求完整标题与目标一致。
2. 优先用当前可访问性文本、可见标签和窗口标题定位。
3. 只有在最新截图上才可使用窗口内相对位置；界面变化后立即废弃旧位置。
4. 找不到预期入口时重新观察一次；仍无法确认则报告当前可见内容并停止。
5. 不根据版本号推断某个命令必然存在，也不回退到历史坐标。

基线版本以外只能称为“按语义定位设计上兼容”。只有在对应安装版本上完成真实流程后，才能称为“已验证兼容”。
