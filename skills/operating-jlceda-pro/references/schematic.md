# 原理图

步骤顺序与学习中心快速入门一致。每一步的入口和快捷键见 `tutorials.md`；窗口与教程不符时按窗口执行并记录。

## 1. 工程与图页

- 新建：`文件 - 新建 - 工程`（或开始页“快速开始 - 新建工程”），填工程名后保存；再 `文件 - 新建 - 原理图`。
- 修改已有工程：打开用户指定的工程，确认窗口标题中的工程名，按 `intake.md` 处理备份和未保存改动。
- 确认快捷键主题和网格设置。

## 2. 选器件

器件表中每一项在放置前确定具体库器件：

1. 用 `放置 - 器件`（`Shift+F`）打开器件对话框搜索。结果不理想时切换搜索引擎（立创商城 / 嘉立创EDA）。
2. 切换到表格列表，预览符号、封装和 3D，核对：型号与器件表一致；引脚数和引脚编号与图或数据手册一致；封装符合用户的贴片或通孔要求。
3. 用户要用嘉立创下单或贴片时，记录界面可见的立创编号、库存和价格。这些信息只代表本次观察，不凭记忆填写。偏好基础库器件时，以界面实际标注为准。
4. 用户没有说明品牌偏好时，按默认规则选择，不逐个器件询问：型号完全匹配的优先选原厂；通用阻容和 LED 优先选界面标注为“基础库”的器件；同类器件尽量选同一品牌。选择结果写进报告，用户可以再改。只有用户明确在意成本或品牌，或候选之间参数有实质差异（精度、耐压、颜色等）时，才列出候选让用户选。所选器件显示缺货或停产时报告给用户，不静默替换。
5. 器件名、供应商封装、3D 模型和实际 PCB 封装可能互相矛盾（实测中名称含 `0603` 的器件实际是通孔封装）。封装以实际 PCB 封装字段为准，其余字段不能替它作证。

## 3. 放置与布局

- 放置：在器件对话框选中后点“放置”。需要先改位号、值或封装时，放置前按 `TAB` 设置。放完一个器件按 `ESC` 退出，或接着放下一个。
- 位置与朝向：图片输入按 `layout-fidelity.md`；文字输入按常规画法（信号从左到右，电源在上、地在下，按功能块分组）。
- 旋转用空格，翻转用 `X` / `Y`；对齐、分布用 `布局` 菜单。
- 放置后选中器件，在右侧面板核对并修改位号和值，按“读两次”规则确认。

## 4. 连线

- 导线：`放置 - 导线`（`Alt+W` 或 `W`，取决于快捷键主题）。左键确定线段，右键取消。光标靠近引脚会吸附；画完确认两端确实落在目标引脚或节点上，重叠的线段不代表已经接通。
- 连接点：需要连接的十字交叉处放“连接点标识”（`Alt+J`）。十字交叉默认不连接。
- 网络标签：`放置 - 网络标签`，放置时按 `TAB` 设名称；标签必须落在导线或引脚上才生效。网络名逐字核对，大小写和符号都要一致。
- 电源和地：用网络标识（VCC、GND 等）；网络名与器件表一致。
- 未使用的引脚：用户或数据手册要求悬空时放“非连接标识”，只能放在引脚端点上。
- 多页或层次图：页间用跨页连接标识或网络端口，按教程处理。

## 5. 每个功能块完成后核对

- 器件数量、位号、值与器件表一致；
- 有极性器件方向正确（电解电容正极、二极管和 LED 阳极、三极管引脚）；
- 引脚号和网络关系与网络表一致；
- 连接点和不连接的交叉符合确认结果；
- 网络标签、电源和地标识完整，字符准确；
- 多单元器件的各单元都已放置，隐藏电源引脚的接法已确认；
- 有意悬空的引脚已标记并记录。

核对通过后保存（`Ctrl+S`），向用户汇报进度，再进入下一个功能块。

## 6. 原理图 DRC

1. `设计 - 检查DRC`，结果在底部面板 DRC 栏。V4.1.60 中原理图检查也叫“检查DRC”，报告中使用界面实际名称。
2. 逐项处理：设计错误要修正；有意保留且能解释的警告记录在报告中。特别注意“导线是单网络，仅连接了一个元件引脚”和“元件引脚悬空”这两类警告：它们通常说明导线终点差了一格网格，没有真正连到引脚。放大到 600% 以上查看，把导线段拖到引脚端点上，然后重新运行检查。
3. 再到左侧“网络”页核对每个网络的引脚数，与网络表一致才算连接正确。
4. 出现“建议使用器件标准化”时按教程处理。
5. 不通过删除网络、隐藏问题或批量忽略规则来制造零错误。

## 7. 完成

保存后重新观察整张原理图，对照器件表和网络表逐项检查；图片输入再完成 `layout-fidelity.md` 的版面核对。所有阻塞项解决、封装都已确认，才进入 PCB。
