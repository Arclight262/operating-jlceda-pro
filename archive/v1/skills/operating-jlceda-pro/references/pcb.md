# PCB 检查契约

## 转换前

- 确认原理图已保存，相关规则检查结果已处理或解释。
- 为每个器件分别核对符号与电气身份、引脚映射、实际 PCB 封装、供应商属性和 3D 模型。PCB 布局以已验证的 PCB 封装与焊盘映射为依据；任一字段不能自动证明其他字段正确。
- 库字段冲突时记录冲突字段及其原值。尺寸、焊盘、引脚或极性兼容性不能由数据手册、封装图或用户输入确认时，停止选型或同步并询问。
- 确认板框尺寸、层数、安装孔、接口位置和布局约束。输入未规定且会影响成品时先询问。

## 适用性驱动的规划

按原理图、约束台账和实际用途为每个功能块建立功能块风险画像，可用类别包括机械固定、电源或大电流、开关节点、去耦、时钟、高速或受控阻抗、差分、模拟敏感、射频、热设计、安全和制造。只标记实际存在且有证据的类别；不得为不存在的接口或功能块添加约束。

布局和布线顺序由本项目的依赖、机械限制和风险画像决定，不使用无条件固定模板。例如：存在板边连接器或安装孔时先处理机械固定；存在开关电源时优先收紧关键电流环路；存在需要去耦的 IC 时优先放置对应电容；存在受控阻抗接口时先确认层叠和阻抗方案。某个条件不存在时跳过对应步骤，并在台账标为不适用。

## 原理图到 PCB 同步

把每次同步视为可能影响全板的事务：

1. 同步前保存工程，并记录器件/封装数量、网络数量、未布网络或飞线、已有走线和当前检查结果；能创建客户端检查点或备份时记录其可见位置。
2. 只执行一次明确的同步或导入，随后重新观察画布和计数。
3. 形成同步前后差异，至少比较新增/删除器件、封装、网络、飞线、走线和板框。
4. 若出现输入未要求的删线、网络变化、器件移动或板框变化，立即停止并报告影响。未经用户明确授权不得重新布线、删除网络或用再次同步覆盖现场。
5. 用户确认恢复策略后再执行恢复或重布线；完成后重新检查全部网络和 DRC，不把恢复动作隐藏在最终报告中。

## 板框与布局

确认板框闭合、尺寸正确且没有意外重叠。根据当前功能块风险画像，按适用的电气功能、信号路径、回流路径、散热、机械边界和可装配性要求布局。连接器、指示器和有极性器件需同时核对朝向与可访问性。

先完成受机械位置约束和会决定关键路径的器件，再完成相关局部器件，最后安排没有特殊约束的器件。每完成一个功能块，复查它与相邻功能块的接口、回流和空间冲突；不因文章示例使用了彩色区域、星形供电或特定距离而在当前设计中自动复现。

移动或旋转器件后立即观察其位号、封装和飞线变化。不得仅因画面整齐就认定布局正确。

## 布线

先按约束台账标识关键网络，并只对实际存在的类别排序：受控阻抗或差分、时钟、开关电源关键环路、电源或大电流、模拟或射频敏感网络，以及普通网络。不同项目可以得到不同顺序；同一网络同时命中多类时形成联合约束，确认各项能够同时满足，发生冲突时停止并询问用户。

依据已确认的网络和当前规则布线。每条关键网络完成后核对端点、层、过孔、参考平面、回流路径和邻近铜。固定线宽、间距、等长、阻抗和过孔数量必须来自约束台账，不从教程示例推断。自动布线只能用于用户明确允许的普通网络；关键网络先锁定或手工完成，自动布线后再次核对关键网络、回流路径和全部未布网络。不要用删除网络、忽略未布线提示或覆盖规则来减少错误数。

当工程实际需要差分、等长、xSignals、局部约束、铜皮优先级、缝合过孔或泪滴时，按 [advanced-pcb.md](advanced-pcb.md) 的适用性门槛、操作契约和证据要求执行。高级功能不是完成清单；不存在明确对象和约束来源时不启用。

## DRC 与完成检查

运行当前版本中能够明确定位的 DRC 入口并逐项处理。至少检查：

- 原理图与 PCB 器件、位号和封装一致；
- 板框存在、闭合且尺寸符合输入；
- 必需网络全部布通，没有意外短路或未布网络；
- 极性、接口方向和机械约束正确；
- DRC 错误已修正，剩余告警有明确解释。

再按功能块风险画像检查所有标为适用的专用项，并把不适用项与未验证项分开。没有高速接口时不要求差分或阻抗验收；没有大电流路径时不套用大电流线宽和过孔规则；没有射频功能时不添加射频布局约束。DRC 没有覆盖的适用约束必须人工复查或用对应工具验证。

保存后重新观察工程、PCB 画布和检查结果。最终报告必须如实给出未布网络数、DRC 结果和仍未解决的限制。

当输入要求、连接、封装、板框和当前规则集检查均满足时，只报告“编辑验收通过”。若电源与地线宽、间距、回流路径、热设计、EMC、装配可达性或制造商规则中的任何适用项缺少明确依据，报告“生产就绪未验证”并列出缺口。只有用户或制造商提供的规则值经过核对和实际检查后，才可提升为“生产就绪已验证”；不得自行编造规则值。
