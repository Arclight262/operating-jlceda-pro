# 输入工作流与提问协议

## 共用准备

1. 枚举嘉立创 EDA 窗口并按完整标题核对目标。候选不唯一时列出候选并询问用户，不按窗口顺序或最近使用时间猜测。
2. 确认工程名、目标文件、当前编辑器和阻挡对话框。
3. 建立任务清单，并把每个输入项标为 `已确认`、`待确认` 或 `无法识别`。
4. 与当前步骤相关的电气阻塞项未归零前，不开始该部分绘制。

## 自然语言新建

把需求整理为器件身份、参数、供电、接口、网络关系、极性、封装和板级约束。只追问会改变电气正确性或后续 PCB 结果的缺失项。信息完整后按功能块绘制；每个功能块完成后对照清单并保存。

## 图片复刻

只记录图片中可见的事实：器件外形、可辨文字、位号、数值、引脚、网络标号、极性符号和连接关系。放大仍不能唯一确定的内容保持 `待确认` 或 `无法识别`，不得借常见电路、周围拓扑或器件概率替用户作决定。

提问格式：

```text
位置：<页码/区域/位号/相邻器件>
可见事实：<可靠可辨的文字或连接>
候选解释：<存在时列出；不强行凑候选>
请补充：<完整型号、数值、清晰局部图或连接判断>
影响：<器件选择、封装、网络或后续 PCB>
```

对于模糊的导线交叉，直接询问“相连还是仅交叉”；确认前不创建网络、连接点或任一默认解释。对于模糊器件，确认前不选择具体后缀或通用替代符号。

实物 PCB 照片只能作为补充证据，不能单独用于恢复完整原理图。

## 修改已有工程

直接修改用户指定的原工程，不默认另存副本。操作前记录目标对象及原值，只触及请求涉及的内容。若任务开始时已有来源未知的未保存改动，先询问用户如何处理；修改请求本身不等于允许覆盖、合并或保存这些改动。

## 恢复与证据

动作超时、刷新失败或反馈不明确时，把结果记为未知，重新观察控件值和画布状态后再决定是否重试。需要撤销时，先确认目标工程和当前状态，只撤销一次并立即复查。

完成报告至少包含工程名、修改范围、保存状态、检查结果、未解决项以及能证明最终状态的窗口标题或画布观察。
